# 书稿与 GitHub 的同步

网页里"通过"一个任务时，容器只把分支合并进树莓派上的书稿主克隆 `~/BookSmith/book` 的 `master`（容器里没有任何 GitHub 凭据）。和 GitHub 私有仓库 `king157419/llm-book` 的同步由树莓派宿主机负责：

- `booksmith-book-sync.timer` 每 5 分钟运行 `deploy/sync_book.sh`：
  - 树莓派领先（审核通过的改动）→ 推送到 GitHub
  - GitHub 领先（你在自己电脑上推了提交）→ 树莓派快进
  - 双方分叉 → 什么都不动，服务标记为失败，等人工合并
- 只做快进，**绝不强推**。
- 凭据：树莓派 `~/.ssh/booksmith_book_deploy`，在 GitHub 上登记为 llm-book 仓库的**部署密钥**（只对这一个仓库有效，可读写）。走 `ssh.github.com:443`（`~/.ssh/config` 里的 `github-book` 主机别名）。

## 你在自己电脑上改书稿时

1. 改之前先 `git pull`，把智能体合并的改动拉下来。
2. 改完尽快 `git push`。
3. 如果正好和智能体的合并撞上（分叉），树莓派会停止同步：`ssh pi-lan journalctl -u booksmith-book-sync -n 20` 能看到提示。处理方法：在树莓派 `~/BookSmith/book` 里 `git pull --no-rebase origin master` 合并后，`sudo systemctl start booksmith-book-sync`。

## 常用命令

```sh
systemctl list-timers booksmith-book-sync.timer
journalctl -u booksmith-book-sync -n 20
sudo systemctl start booksmith-book-sync      # 立即同步一次
```
