# 入口服务器与隧道

```
浏览器 ──http──▶ 入口服务器 124.220.163.249（腾讯云，nginx :80）
                    │ /booksmith/ → 127.0.0.1:8100
                    ▼
              SSH 反向隧道（树莓派主动连出）
                    ▼
              树莓派 127.0.0.1:8100（BookSmith 容器）
```

访问地址：`http://124.220.163.249/booksmith/`（根路径 `/` 会跳转过来）。

## 入口服务器（ubuntu@124.220.163.249，私钥在本机 `~/.ssh/lmy.pem`）

- nginx 配置：`/etc/nginx/sites-available/booksmith`（本目录 `nginx-booksmith.conf` 是同一份），已删除 nginx 默认站点。
- 隧道授权：`~ubuntu/.ssh/authorized_keys` 里 `booksmith-tunnel@pi` 那一行，限制为只能反向转发 `127.0.0.1:8100`，不能登录、不能执行命令。
- 腾讯云防火墙已放行 80 端口（2026-11-24 实测外网可访问）。

## 树莓派

- 隧道服务：`/etc/systemd/system/booksmith-tunnel.service`（本目录同名文件），开机自启，断线 10 秒后重连。
- 隧道私钥：`~/.ssh/booksmith_tunnel`（只用于这条隧道）。
- 常用命令：`systemctl status booksmith-tunnel`、`journalctl -u booksmith-tunnel -f`。
