# 市面同类智能体调研

> 2026-11-24。链接都是这次搜索中实际打开或搜到过的；star 数是近似值；没核实到的标"待核实"。

## 0. 结论先说

1. **市面上没有现成产品能做"维护一本已有的 LaTeX 教材"。** 教师类产品（MagicSchool、讯飞、希沃）都是"从零生成一份教案、课件"，不管已有书稿；开源项目各自只解决一段（做课件、写长文、出题）。我们要做的事情里，最接近的是 **"Issue → 智能体改仓库 → 提 PR"** 这一类编码智能体。
2. **所以最省力的做法是"拼"，不是"从零写"：** 用一个能接 DeepSeek、能无界面运行、能加载 SKILL.md 的开源编码智能体当执行层（首选 **OpenCode**），把"维护 / 出题 / 做课件 / 写新章"写成技能，我们自己只写网页和机器人这层薄壳，再加上编译和自检脚本。
3. **DeepSeek 正好合适：** 当前的 `deepseek-flash` 有 1M 上下文，支持工具调用、JSON 输出、**看图**，同时提供 OpenAI 和 Anthropic 两种兼容接口，价格很低（详见第 6 节）。

## 1. 最值得借鉴的 5 个设计

| # | 设计 | 来自 | 用在我们这里 |
|---|---|---|---|
| 1 | **生成 → 自检 → 检查工具 → 编译 → 报错回喂**，全程留在 LaTeX 里 | paper2slides | 维护和出新都走这个闭环；课件如果用 Beamer，也直接复用 |
| 2 | **一份源文本派生所有形式** | Google Learn Your Way | 章节 LaTeX 是唯一真源，习题、课件都从它派生；章节一改，就提示相关习题和课件要重新生成 |
| 3 | **用 Issue 或标签触发，用 PR 收尾**，权限最小化，人工合并 | Jules、Claude Code Actions、Copilot | 网页或飞书上的需求转成任务，智能体在分支上改，最后提 PR |
| 4 | **先预写作，再写作**：多角度提问 → 检索 → 大纲 → 人确认大纲 → 逐节写 | STORM、OpenMAIC | "出新"阶段必须先让人确认大纲，再动笔 |
| 5 | **技能可以跨智能体复用** | OpenCode、PPTAgent Skill、DeepTutor | 能力写成 SKILL.md，以后换执行层（OpenCode / Claude Code / Codex）不用重写 |

## 6. DeepSeek API 现状（官方文档，已核实）

来源：[模型与价格](https://api-docs.deepseek.com/quick_start/pricing)

| 项目 | `deepseek-flash`（V4.1-Flash-1017） | `deepseek-v4-pro`（V4-Pro-0813） |
|---|---|---|
| 上下文 / 最大输出 | 1M / 384K | 同左 |
| 思考模式 | 支持思考与非思考，默认思考 | 同左 |
| 工具调用、JSON 输出 | 支持 | 支持 |
| 看图 | **支持** | 不支持 |
| 接口格式 | OpenAI、Anthropic、Responses API | 同左 |
| 输入价（未命中缓存，非高峰） | 0.15 美元 / 百万 token | 0.66 美元 / 百万 token |
| 输出价（非高峰） | 0.6 美元 / 百万 token | 1.98 美元 / 百万 token |

- **高峰时段价格翻倍**：周一到周五 UTC 01:00–04:00、06:00–10:00，即北京时间 9:00–12:00、14:00–18:00。批量任务尽量放到晚上和周末跑。
- **自己写智能体循环时有个坑**：思考模式下，只要请求带了工具，后续每次请求都必须原样回传 `reasoning_content`，否则报 400（[文档](https://api-docs.deepseek.com/guides/thinking_mode)）。用 OpenCode 这类现成执行层，要确认它处理了这一点。
- JSON 模式要求提示词里出现"json"字样，解析失败时要有重试（[文档](https://api-docs.deepseek.com/guides/json_mode)）。

粗算一下：维护一次书稿大约读 10 到 30 万 token、写 1 到 2 万 token，用 Flash 非高峰大约 **0.02 到 0.06 美元一次**。经费压力很小。

## 7. 对方案的影响

- **执行层倾向定为 OpenCode + DeepSeek**（方案文档 7.2 节的选项 B）。M1 先用它跑通 3 个测试任务，跑不顺再考虑自己写循环。
- **课件两条路都有现成参考**：沿用现有 PPT 模板就参考 PPTAgent（它有 OpenCode 技能版）；走 Beamer 就参考 paper2slides。看老师更想要哪种。
- **"出新"阶段加一道"人确认大纲"**，借鉴 STORM。
- **查资料可以接 GPT Researcher 或直接用 Tavily**，M4 时再定。
