# M0 / M1 需求文档

> 2026-11-24。给开发者（Antigravity 或 Claude）照着做的文档。每一步都有验收标准，做完一步验一步。

## 背景：现在书稿是怎么编译的

看了 `D:\desk\llm\book\build.sh`，现在的流程强依赖这台 Windows 电脑：

| 环节 | 现状 | 搬上树莓派的问题 |
|---|---|---|
| 编译环境 | 本机的 `sharelatex` 容器（TeX Live 2026，XeLaTeX），`docker cp` 把文件拷进去编 | 要换成自己的镜像 |
| 中文字体 | 宋体、黑体、仿宋、楷体、微软雅黑，**直接读 Windows 的字体文件**（`\zhfontpath`） | 见下面"决策 1" |
| 西文 / 数学字体 | TeX Gyre Termes / Heros、Latin Modern Mono、TeX Gyre Termes Math | TeX Live 自带，没问题 |
| 索引排序 | `tools/make_index.ps1`，**用 PowerShell 和 Windows 的拼音排序规则** | Linux 上跑不了，要改写 |
| 编译次数 | xelatex ×2 → 排索引 → xelatex ×2 | 不变 |
| 用到的宏包 | ctex、fontspec、unicode-math、tikz、pgfplots、tcolorbox、siunitx、natbib、hyperref 等约 40 个 | TeX Live 完整版都有 |

## 需要你先拍板的两件事

### 决策 1：中文字体怎么办

宋体、黑体、微软雅黑这些是微软的字体，许可只允许在装了 Windows 的电脑上用，**拷进 Docker 镜像放到树莓派上，违反许可**。有三种做法：

| 做法 | 版面 | 许可 |
|---|---|---|
| A. 换成开源字体：思源宋体 / 思源黑体（或 Fandol），楷体、仿宋找开源替代 | **会变**：字形和字宽不同，分页、图表位置要重新检查一遍 | 干净 |
| B. 继续用微软字体，只在树莓派上挂载、不打进镜像 | 不变 | 仍然不合规，只是没有对外分发 |
| C. 树莓派只编"预览版"（开源字体），正式版 PDF 仍在 Windows 上编 | 预览版和正式版略有差别 | 干净 |

**我倾向 A**：一次性换掉，以后在哪都能编，也方便把书稿交给别人。代价是要过一遍全书版面（441 页），可以让智能体先跑一遍、只看警告和缩略图。

### 决策 2：镜像在哪里打

| 做法 | 说明 |
|---|---|
| **树莓派自己打（推荐）** | 同一份 Dockerfile 放在 Git 里，电脑上打 x86 版用于开发测试，树莓派上打 ARM 版用于运行。树莓派原生打包快，不占本机 C 盘 |
| 电脑上交叉打 ARM 版 | 要模拟 ARM，装 TeX Live 会非常慢；本机 C 盘只剩 17G，还要先把 Docker 数据挪到 D 盘 |

## M1：维护（命令行版）

目标：**在树莓派上给一句需求，智能体在分支上改好、编译、自检，然后提 PR。**

### 组成

- **执行层**：OpenCode（无界面模式 `opencode run`），接 DeepSeek（`deepseek-flash`，OpenAI 兼容接口），装进同一个镜像。
- **技能**：把 `textbook-writing`、`HANDOFF.md`、`SPEC.md` 整理成 `skills/textbook-maintain/SKILL.md`，去掉 Windows 路径、Overleaf 这类个人化内容。挂载进容器，不打进镜像。
- **任务脚本**：`agent run "需求"`，依次：
  1. 从 main 拉一个新分支 `agent/<日期>-<短名>`
  2. 调 OpenCode 改稿（工作目录只限书稿仓库）
  3. 编译；失败把报错喂回去修，最多 3 次
  4. 自检（见下）
  5. 推送分支，提 PR，正文写"改了什么、为什么、自检结果"，附 PDF（作为 PR 附件或 Release 资产）
- **自检脚本**：
  - 改动前后的章节数、字数、公式数、图表数，异常减少就失败
  - 术语表、符号表一致性
  - `\ref` / `\cite` 都能解析
  - 只允许改需求涉及的文件，改了别的就标出来

### 权限

- 容器只挂载书稿仓库、技能目录、配置；不挂载代理配置、SSH 私钥等其他东西
- GitHub 用**只对这一个仓库有效**的细粒度令牌，只能推分支、开 PR，不能推 main
- DeepSeek key 和 GitHub 令牌只放在树莓派的私密文件里，不进任何仓库

### 测试任务（用书稿历史上真实做过的修改）

| # | 任务 | 判断标准 |
|---|---|---|
| T1 | 把某张表里的模型型号更新为指定的新型号（类似 11-17 改表 1-6） | 只改那张表；编译通过；数据和给定资料一致 |
| T2 | 全书统一一个术语（类似"规模定律 → 缩放定律"） | 漏改为 0、误改为 0（对比 `grep` 结果） |
| T3 | 按一条老师批注改写一段例题 | 改动符合批注；例题数值自洽；编号和引用没乱 |

验收：三个任务各跑 3 次，每次都提出正确的 PR；记录每次的耗时和 DeepSeek 费用。
