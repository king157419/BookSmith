# 出习题

前提：已读 `booksmith-book`。本技能的产物是**独立于正文的习题文件**，不修改任何章节的 `.tex`（包括书里自带的"习题"一节）。

最重要的一条：**题目的答案必须是你自己先解出来、并且验算过的。** 一道答案有误的题比没有题更糟。数值不自洽就改题，不要改答案去将就。

## 一、产物

```
exercises/common.tex        公共部分（已存在则不改；不存在就从本技能 templates/common.tex 复制）
exercises/chNN/body.tex     题目与答案，唯一来源（NN 为两位章号，如 ch03）
exercises/chNN/student.tex  学生版入口：\answersfalse
exercises/chNN/teacher.tex  教师版入口：\answerstrue
```

两个入口只差一个开关（`\newif\ifanswers`），题目和答案都写在 `body.tex` 里，所以**两个版本的题目一定一致**。模板在本技能的 `templates/` 目录：`common.tex`、`student.tex`、`teacher.tex`、`body.tex`（含一道选择题和一道计算题的示范）。复制后把入口里的章号 `3`、`ch03`、标题换成实际值。

字体和样式与书稿完全一致：入口文件加载 `bookstyle`（宋体、黑体、盒子、`\SI` 等），不要另加字体或宏包。

### 编译

```
sh tools/build_linux.sh --file exercises/chNN/student.tex   → exercises/chNN/student.pdf
sh tools/build_linux.sh --file exercises/chNN/teacher.tex   → exercises/chNN/teacher.pdf
```

两个都要编，且都要通过（返回码 0）。**注意**：`--file` 参数是否可用取决于构建脚本；若脚本报"未知参数"，不要自己改脚本、不要换命令，在最终说明里写"习题源文件已写好但未能编译，需要构建脚本支持 `--file`"，其余工作照做。（流水线会用同样的方式生成 `学生版.pdf` 和 `教师版.pdf` 交给审核人。）

独立编译的限制：`body.tex` 里**不能 `\ref`/`\cite` 书稿里的标签**（习题单独编，看不到书的编号）。引用书中内容写成"第 3 章 3.4 节""例 3-5""表 3-2"，数字从正文里读出来写死。符号、公式写法和书保持一致。

## 二、流程

### 1. 弄清需求

从请求里确定：哪一章（哪几节）、几道题、题型比例、用途（课后作业 / 期中期末 / 自测）、难度要求、是否需要分值。缺项时按默认：**10 道题**；选择 3、填空 2、简答 2、计算 2、分析/设计 1；难度 基础:中等:提高 ≈ 4:4:2；用途按"课后习题"；不写分值。用途是考试时才加分值，并让总分为 100。把你采用的默认值写进最终说明。

### 2. 读章，列知识点表

通读该章全部 `.tex`（节、例题、辨析框、小结、**已有习题与部分习题提示**、本章术语表）。写出这张表（放进最终说明）：

| 知识点 | 所在节 | 书中已有例题/习题 | 本次是否出题 |
|---|---|---|---|

- 核心知识点 = 小结里逐条回顾的那些"每节回答的问题"，加上本章公式汇总表里的公式和每个例题的题型。
- **每个核心知识点至少被一道题覆盖**；题数不够覆盖时，优先选考试价值高的（公式应用、易混概念辨析、机制说明），并在说明里写出没覆盖的点。

### 3. 查重

先读该章已有的"习题"节（如 `chapters/ch3/14-exercises.tex`）和所有 `example` 环境。你的题与它们**不能是同一道题换了个说法**：
- 考查同一知识点是可以的（核心知识点本来就会反复考），但**场景、数据、问法**至少有两项不同。
- 计算题**换一组参数**：例题是 7B，你就用 13B 或 34B；例题求显存，你可以求并发数。
- 不要原样抄书里的例题数据，也不要把已有习题改个数字就算新题。
- 若 `exercises/` 下已有同一章的文件，先读，新增的题避开已出过的。

### 4. 拟题单

每道题先定：题型、难度、考查知识点（对应节）、答案类型。排序规则：按题型分组（选择 → 填空 → 简答 → 计算 → 分析/设计），组内**由易到难**。

难度含义：
- **基础**：直接回忆定义、公式、结论，或套一次公式。
- **中等**：两步以上的推理或计算；区分两个相近概念；解释"为什么"。
- **提高**：综合多个知识点、有隐含条件或需要做判断（如选方案、找瓶颈）、需要说出前提和局限。

### 5. 逐题写：先解答，后出题面

对每道题**先把完整答案写出来**（草稿里），再回头写题面，保证题面里的条件足够推出答案、不多不少、不互相矛盾。题型的具体写法和示例见 `references/problem-types.md`，下面是总要求。

**计算题的硬性要求**
- 答案必须有**完整推导**：用五列表（`calc` 环境：步骤 / 算什么 / 算式 / 结果 / 这个数从哪来），或逐步算式；每个数说明来源；除法和科学计数法加括号。
- **验算**：换一种方法再算一遍（反向代入、换算单位、量级估计、用另一个公式），把验算写进解析里（"验算：……"）。
- **自洽检查**（逐项过）：结果是否合理（显存、时间、占比的量级对不对；百分数不超过 100%；并发数、卡数、层数**取整方向正确**，不能出现 22.99 个对话；除不尽时题目里写明保留几位）；所有条件是否都用上了、没有多余或缺失；单位是否一致（GB 按 $10^{9}$ 字节，用 GiB 要在题里写明）；是否与书里的公式/符号一致（对照 `front/notation.tex` 和对应公式）。
- **数值不自洽就改题**：数据凑不出合理结果时，调整题目参数，直到结果整洁且合理；绝不能为了对上答案去改公式或"凑"答案。
- 不要出需要查表才有的数据而题里没给；需要的参数（峰值算力、带宽、层数、隐藏维度）都在题面给全。

**选择题**：四个选项，**有且只有一个正确**；干扰项来自真实的常见误解（解析里说明每个干扰项错在哪）；选项长度相近，不用"以上都对/都不对"；正确答案的位置在全卷里大致均匀。避免"下列说法错误的是"这类双重否定。

**填空题**：每空答案唯一且简短（一个术语、一个数、一个公式），不挖虚词；一空一个知识点；不把一整句话挖空。

**简答题**：答案给出**要点清单**（每个要点一句话，注明建议分值），并注明"答出其中 N 点即可"。

**分析/设计题**：给出参考答案的**结构和要点**，列出评分维度（是否说清前提、是否估算了关键量、是否指出瓶颈与权衡），说明"答案不唯一，只要……即可"。设计题要给出明确的场景和约束数据。

**每道题的解析末尾加一行**"考查：第 N 章 N.N 节 xxx"，供审核和教师选题用。

### 6. 写文件、编译

- 题目、答案都写进 `body.tex`，用 `\problem{类型}{难度}{题干}{答案与解析}`（宏的定义见 `common.tex` 头部注释）。题型分组用 `\probgroup{一、选择题}`。
- 数学写法、符号、单位和书保持一致：`$C\approx6ND$`、`\SI{14}{GB}`、`$\lvert\mathcal{V}\rvert$`；全角中文标点；术语用书中的写法（见 `booksmith-book/references/terms.md`）。
- 编译学生版和教师版。**学生版不能泄露答案**：答案只能写在 `\problem` 的第 4 个参数（答案与解析）里，题干（第 3 个参数）和 `body.tex` 的其他位置不得出现答案信息；教师版每题都应有答案框。
- 提交只加 `exercises/` 下你新建或修改的文件（不要提交 `.pdf`、`.aux`、`.log`）。

### 7. 最终说明（给审核人）

按 `booksmith-maintain` 末尾的说明结构，但内容替换为：

```markdown
## 任务
<章、题数、用途；采用了哪些默认值>

## 题单
| 题号 | 题型 | 难度 | 考查知识点 | 所在节 | 答案（简） |
|---|---|---|---|---|---|

## 知识点覆盖
<知识点表，标出每个知识点对应题号；未覆盖的点和原因>

## 验算记录
<每道计算题：用了什么方法验算、结果是否一致；有无因数值不自洽而改过题>

## 与已有习题/例题的查重
<已读了哪些已有习题和例题，哪几道题考查同一知识点但场景/数据不同>

## 编译
学生版：通过/未编译（原因）；教师版：通过/未编译（原因）

## 待人确认
<可能有歧义的题、答案不唯一的题、书中口径有争议的点（例如不同口径得到不同数值时怎么选）>
```

## 三、质量红线（任何一条不满足都不能提交）

1. 每道题的答案都是你推出来的，计算题有验算。
2. 学生版没有答案信息；教师版有答案与解析。
3. 题目与书中已有习题不是同一题。
4. 题面条件充足、无矛盾；需要的数据题里都给了。
5. 数字、单位、符号与书一致；GB/GiB 口径写明。
6. 事实性内容（模型参数、年份、产品名）只用书里已有的；不引入书里没有且你无法核实的新事实。
7. 作者口吻，不出现"答题时""根据课件"等字样；不提"第几讲"。

## 四、需要时读

- `references/problem-types.md`：五类题型的完整示范（题面 + 答案 + 解析各一例，含计算题五列表与验算写法）。**写任何一类题之前读对应的一节。**
- `templates/`：复制即用的文件模板。
